生產線 Cycle Time 計算器

上傳作業紀錄 CSV，自動計算各工作站平均 Cycle Time，以及整條生產線的瓶頸 Cycle Time。

1. 上傳 CSV 檔案

選擇你的生產紀錄 CSV
檔案需包含 station_id 與 duration_sec 欄位。支援 UTF-8 CSV。
尚未上傳檔案。

2. 計算結果

上傳 CSV 後，這裡會顯示計算結果。

3. 各工作站 Cycle Time

等待資料計算

4. 計算方式

工作站 Cycle Time = 該工作站作業時間總和 ÷ 該工作站有效作業筆數。

整條生產線 Cycle Time（瓶頸估算） = 所有工作站平均 Cycle Time 中的最大值。

單件產品總加工時間（參考） = 各工作站平均 Cycle Time 相加。這個數值與整條生產線的瓶頸 Cycle Time 不同。

本工具會排除 duration_sec 或 station_id 空白、以及 status 欄位存在且不是 COMPLETED 的資料。若選擇「最後 9 筆」，會先依 CSV 原始順序篩選有效紀錄，再取最後 9 筆。
所有計算都在你的電腦瀏覽器內完成，CSV 不會上傳到網路伺服器。
